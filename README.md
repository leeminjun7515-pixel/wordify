# 🌟 Wordify (워디파이)
> *"The moment a word becomes my own—Wordify"*

퀴즐렛(Quizlet)의 편리한 단어 암기 시스템과 듀오링고(Duolingo)의 게이미피케이션(XP, 리그 리더보드, 스트릭), 그리고 한자/비로마자 획순 그리기 캔버스 학습이 결합된 올인원 단어 학습 플랫폼입니다.

---

## ✨ 구현된 핵심 기능

### 1. 🎨 3가지 테마 모드 & `#ffe050` 브랜드 디자인
- **화이트 모드**: 깔끔한 화이트 배경과 블랙 텍스트
- **다크 모드**: 눈이 편안한 짙은 차콜 다크 배경과 화이트 텍스트
- **웜 모드 (Warm)**: 은은하고 따뜻한 크림 아이보리 배경과 텍스트
- 모든 테마에 Wordify의 시그니처 `#ffe050` 옐로우 포인트 컬러 완벽 적용

### 2. 📚 3대 집중 학습 모드
1. **🃏 낱말카드 (Flashcards)**:
   - 3D 부드러운 카드 뒤집기 애니메이션
   - 단어, 발음 기호, 뜻, 예문 제공
   - Web Speech API를 활용한 실제 원어민 발음(TTS) 듣기 지원
   - '알고 있음' / '다시 학습' 진행률 추적

2. **✏️ 스펠링 학습 (Spelling & Drawing)**:
   - **로마자 언어 (영어, 말레이어 등)**: 키보드 직접 타이핑 스펠링 확인 모드
   - **비로마자 언어 (한자, 일본어 가나 등)**: **HTML5 캔버스에 직접 마우스나 터치펜으로 획순을 그려보는 드로잉 학습 모드** (지우개, 획순 가이드 오버레이 지원)

3. **📝 테스트 모드 (Test)**:
   - 실전 4지 선다형 퀴즈 테스트
   - 정답 시 즉시 보너스 XP 획득

### 3. 🎮 게이미피케이션 & 커뮤니티
- **🔥 연속 학습 스트릭 (Streak)**: 매일 학습 완료 시 스트릭 카운트
- **⚡ 실시간 XP 적립 시스템**: 카드 학습(+10), 스펠링 완성(+15), 테스트 통과(+25)
- **🏆 주간 다이아몬드 리그 리더보드**: 매주 갱신되는 1~10위 랭킹 & 챔피언 뱃지
- **🏅 뱃지 보관함**: 스트릭 뱃지, 랭킹 뱃지, 단어 정복 뱃지 수집
- **🌍 탐색 (Explore)**: 다른 사용자들이 만든 세트 구경 및 공유

### 4. ⚙️ 계정 및 보안 설정
- 프로필 아바타 & 닉네임 변경
- 기본 학습 언어 설정 (한국어, 영어, 말레이어, 중국어, 일본어)
- 이메일 & 비밀번호 변경 (이메일 인증코드 입력 단계 포함)
- 계정 삭제 및 탈퇴 안전장치 (2단계 인증 모달)
